# KPI ダッシュボード v3.1 の実績を台帳から書く（OpsKpi.gs）

KPI シート「TOMODACHI留学_KPI_v3.1」（タブ `v3.1`）の実績を、毎晩23時の opsDaily が台帳（受講・生徒_JP・生徒_海外）と Stripe から書く。

## 何をどこから書くか

| 行 | 出どころ | 数え方 |
|---|---|---|
| フォーム申込数 | 生徒_JP の申込日時 | 経由は問わない（LP も activo も）。既存照合がある行は数えない |
| 新規入会数(JP) | 受講の開始日 | その人の最初の開始日の月 |
| 復帰 | 受講 | 退会のあとに足した行の開始日の月。メモに「復帰」と書いた行も |
| 退会者数 | 受講の最終日 | 最終日の翌月1日までに次の行の開始日が無ければ、最終日の**翌月**の欄（休会も同じ。クラス替え・GAP への切り替えは数えない） |
| MRR実績（OS） | 受講（G で始まる生徒ID） | その月に受講している海外生 × OS単価（シートの「OS単価」・600円）。2クラスでも1人 |
| GAP新規・うち直行新規・GAP離脱・うちコンボ | 受講（クラス一覧の種別が GAP） | GAP 離脱も1か月遅れ。コンボ＝月末に GAP と GAP 以外の両方を受講 |

- 書く月：2026/12 から（フォーム申込数・MRR（OS）は 2026/11 から）。毎晩、先月・今月・来月を書き直す。先月より前の欄はもう変えない。
- 式の入っているセルには書かない。書いたセルのメモに「自動（台帳から・日時）」と数えた人の名前（Display name）が入る。
- 月の列が無ければ右に足す（見出しと式を写す）。
- MRR実績（JP）は Stripe の `revenue.mrr`、広告費はマネーフォワードの仕訳から、毎月 Claude が入れる（GAS は書かない）。
- 週1の見張りメールに出すもの：休会のまま1年を過ぎた人／在籍で受講しているのに Stripe で請求していない人／Stripe で請求しているのに受講していない人（Stripe は参考値。兄弟で1件などのずれは出る）。

## 本番に入れる手順（最初に1回）

1. 生徒管理スプシ →「拡張機能」→「Apps Script」→ ファイルの「＋」→「スクリプト」で `OpsKpi` を作り、`gas/OpsKpi.gs` を貼る。
2. `Ops.gs` を新しいものに貼り替える（3つのファイルIDを入れたもの。Claude がクリップボードに入れる）。
3. 「プロジェクトの設定」→「スクリプト プロパティ」に `KPI_FILE_ID` ＝ `1O1e8XH-UdafZ04W_beuMOaXJVuWp-cCA2dy3N3A529o` を足す。
4. スプシを開き直し、メニュー「TD台帳」→「Stripe のキーを入れる（最初に1回）」で制限付きキー（`rk_live_`…、Customers と Subscriptions の読み取りだけ）を入れる。
5. 「TD台帳」→「KPI を今すぐ書く」。Claude がシートを読んで確かめる。

`KPI_FILE_ID` が空だと、テスト用の「KPI（自動・テスト）」を作ってそこに書く。

## 運用の決まり
- 休会は最大1年。受講の最終日を入れ、ステータスを「休会」にする（Ops.gs は休会を退会に書き換えない）。1年を過ぎたら「退会」にする。
- 再開したら受講に新しい行を足す（自動で復帰に数える）。
- ずれは「調整」行で合わせる（2026/11 に +1 して台帳の33人に合わせた）。
