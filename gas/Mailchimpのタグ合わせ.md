# Mailchimp のタグを台帳に合わせる（OpsMailchimp.gs）

台帳（生徒_JP のステータス・受講・クラス一覧の種別）を正にして、Mailchimp の TDEN のタグを合わせます。

## 何をするか

| 台帳 | Mailchimp のタグ |
|---|---|
| 在籍 | `TDEN`（GAP のクラスがあれば `TDEN-GAP` も） |
| 休会 | `TDEN-Recess`（`TDEN`・`TDEN-GAP` は外す） |
| 退会 | `Ex-TDEN`（`TDEN`・`TDEN-GAP`・`TDEN-Recess` は外す） |
| 新規・提案中・支払待ち・空き待ち・見送り | 触らない |
| Mailchimp に新しく足す在籍生と、新しく入会した在籍生（受講の開始日が 2026/11/1 以降）で学年タグが無い | `grade9-2026` のような学年タグを1つ（年は申込日の年度。4月始まり。大学1年＝13。台帳の学年に「(25)」とあれば2025年度） |

- 見るのは **生徒_JP だけ**（海外生は Mailchimp に入れない）。
- **台帳にいない人（過去の Ex-TDEN など）と、TDEN 以外のタグ（英検・ほかのプログラムなど）には触りません。**
- Mailchimp にまだ無い在籍生は、「合わせる」の時に連絡先を足して `TDEN` などを付けます（足すのはメールアドレスだけ。名前は入れません）。Email が空の在籍生は「未登録」として知らせます。
- 書き込むのは、メニュー「Mailchimp のタグを台帳に合わせる」で **何人・どのタグかを見て「はい」を押した時だけ**。

## メニュー（TD台帳）

- **Mailchimp のずれを調べる** … 読むだけ。生徒管理の「Mailchimp照合」タブに一覧を作ります。
- **Mailchimp のタグを台帳に合わせる** … 変える件数と中身を出し、「はい」で書き込みます。
- **Mailchimp の API キーを入れる（最初に1回）**

毎週月曜の見張りメール【TD週1チェック】にも、ずれを生徒IDと名前で出します（メールアドレスは書きません）。

## 「Mailchimp照合」タブ（あなた用。メールアドレスが入るので人に見せない）

| 区分 | 意味・やること |
|---|---|
| 合わせる | 「合わせる」を押すと、右の「足す」「外す」のとおりに変わる |
| 台帳に無い | Mailchimp で `TDEN`・`TDEN-GAP` が付いているのに、台帳の生徒と結び付かないメアド。**同じ人の別のメアドなら「生徒ID」欄にその生徒ID（J0012 など）を書く。辞めた人なら `Ex` と書く。** 次に調べた時から台帳に合わせます |
| 別のメアド | 生徒IDを書いて結び付けたメアド（書いたものはタブを作り直しても残る） |
| 足す（未登録） | Mailchimp に入っていない在籍生。「合わせる」で連絡先を足してタグを付ける |
| 未登録 | Email が空の在籍生（足せない）。生徒_JP の Email を埋める |
| 学年が読めない | 新しく入会した生徒の学年が「中学3年生」の形でない。生徒_JP の学年を直す |

## 入れ方

### まずテスト用のスプシで（ダミーの連絡先で動きます。API キーは入れない）
1. 「TDEN 生徒管理（テスト）」→「拡張機能」→「Apps Script」
2. `Ops.gs` と `OpsTestData.gs` をリポジトリの新しいものに貼り替える（テスト用なので Ops.gs の3つのIDは空のまま）
3. 「＋」→「スクリプト」→ 名前を `OpsMailchimp` にして、`OpsMailchimp.gs` を貼る → 保存
4. スプシを再読み込み →「TD台帳」→「Mailchimp のずれを調べる」（初回は外部への接続の許可が出ます）
5. 「Mailchimp照合」タブを見る →「台帳に無い」行の生徒ID欄に生徒IDや `Ex` を書いてみる →「Mailchimp のタグを台帳に合わせる」→ もう一度「ずれを調べる」で減ることを確かめる

### 本番
1. Mailchimp →右上のアカウント → **Profile → Extras → API keys → Create A Key**（名前は `TDEN 生徒管理` など）→ キーをコピー
2. 本番「TDEN 生徒管理」→「拡張機能」→「Apps Script」
3. `Ops.gs` を貼り替える（Claude に「本番用の Ops.gs をコピーして」と言えば、3つのIDを入れたものをクリップボードに入れます）
4. 「＋」→「スクリプト」→ `OpsMailchimp` を作って `OpsMailchimp.gs` を貼る → 保存
5. スプシを再読み込み →「TD台帳」→「Mailchimp の API キーを入れる」→ キーを貼る
6. 「Mailchimp のずれを調べる」→ タブを見て、「台帳に無い」行に生徒IDか `Ex` を書く
7. よければ「Mailchimp のタグを台帳に合わせる」→ 件数を確かめて「はい」

## メモ
- 最初の本番の「合わせる」では、在籍の GAP の生徒に `TDEN-GAP` が新しく付きます（今は Mailchimp にこのタグが無いため、ここで作られます）。
- API キーはスクリプトプロパティ `MAILCHIMP_API_KEY` に入ります。オーディエンスは「AirPangaea」を探して `MAILCHIMP_LIST_ID` に入れます。
- 学年タグを付け始める日は `OPS_MC.GRADE_FROM`（今は 20261101）。
