# TDEN 生徒管理 GAS — 設置・更新手順

`Code.gs` はスプシ「TDEN 生徒管理」にバインドして使う Apps Script です。
このフォルダは `_redirects` でサイトから見えないようにしてあります。

- スプシ: https://docs.google.com/spreadsheets/d/14E9vIHQ46Uew7gFElSsimWIAUnnk8jhXcukGmOKO_eQ/edit
- 役割: LPの申込を受け付けて「生徒_JP／生徒_海外」に書き込む／「クラス一覧」の空き状況をLPに返す／activo と Airtable の通知メールを読み取って書き込む

## 初回の設置（Phase 1）

順番どおりに進めてください。

### 1. 旧GASの定期実行を止める
旧GAS（Japanese Applicants に転記しているプロジェクト）を開き、左の時計アイコン「トリガー」で `checkNewEmails` のトリガーを削除します。
止めないと、同じメールを新旧両方が取り込んで下書きも2通できます。

### 2. Airtable の通知メールに「国」の行を足す
Airtable → Automations →「Admin Notification - New Application」→ メール送信アクションの Message を開き、
1行目「TOMODACHI留学の新規お申込みがありました！」と空行のあと、「■ 名前:」の**上**に次の1行を足します。

```
■ 国: {Country}
```

（`{Country}` は「+」ボタンから Students の Country を選んで差し込む）。保存したら右上の **Update（変更を反映）** を押します。
新しいGASはこの行で「海外の申込」か「LPの予備経路（Japan）」かを振り分けます。

### 3. GASを貼り付ける
1. スプシ「TDEN 生徒管理」を開き、メニュー「拡張機能」→「Apps Script」
2. 最初からある `コード.gs` の中身をすべて消し、`Code.gs` の中身を貼り付けて保存（プロジェクト名は「TDEN 生徒管理」など）
3. 左の歯車「プロジェクトの設定」→ タイムゾーンを「(GMT+09:00) 日本標準時」に

### 4. 合言葉を作る
1. 上部の関数選択で `setApiKey` を選び「実行」
2. 初回は権限の確認が出るので許可（Gmail・スプシ・メール送信・外部からのアクセス）
3. 実行ログに出る `GAS_KEY = xxxxxxxx…` の xxxxxxxx… をコピー（後で Cloudflare に登録）

### 5. 定期実行を入れる
関数選択で `installTrigger` を選び「実行」。以後、5分おきに `processInbox` が動きます。

### 6. ウェブアプリとして公開する
1. 右上「デプロイ」→「新しいデプロイ」→ 歯車で種類「ウェブアプリ」
2. 説明: `v1`／次のユーザーとして実行: **自分**／アクセスできるユーザー: **全員**
3. 「デプロイ」→ 表示される「ウェブアプリのURL」（`https://script.google.com/macros/s/…/exec`）をコピー

「全員」にしても、合言葉（GAS_KEY）が無いリクエストはすべて拒否されます。

### 7. Cloudflare に登録する
Cloudflare → Workers & Pages → TDEN-LP のプロジェクト →「設定」→「変数とシークレット」→ 本番環境に追加:

| 名前 | 種類 | 値 |
|---|---|---|
| `GAS_URL` | テキスト | 6でコピーしたURL |
| `GAS_KEY` | シークレット | 4でコピーしたキー |

Airtable の `AIRTABLE_*` は予備経路で使うので**消さない**でください。

### 8. 動作確認（Claudeに依頼）
ここまで終わったら Claude に伝えてください。LP側をデプロイして、空き状況の表示とテスト申込を確認します。

## コードを更新したとき

Apps Script に新しい `Code.gs` を貼って保存 →「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→「デプロイ」。
こうするとURLは変わりません（「新しいデプロイ」を作るとURLが変わるので、Cloudflare の GAS_URL も直す必要が出ます）。

## 台帳の自動化（Ops.gs）— Phase 3

`Ops.gs` は、Class Structure の一覧表（今月・来月のタブ）・月の記録・週1の見張りメール・生徒シートの列の整理を受け持ちます。
`Code.gs` と同じプロジェクトに、別のファイルとして置きます（関数・定数はすべて `ops`／`OPS` で始まるので、名前はぶつかりません）。
`OpsTestData.gs` はテスト用のスプシにだけ置くダミーデータ作りです。**本番には入れません。**

### テスト用のスプシで試す
テスト用:「TDEN 生徒管理（テスト）」 https://docs.google.com/spreadsheets/d/1VRgvLnGfRyIBZPiP4qBAYJ2wIPGI72JmTbFy7rW9qxU/edit
（生徒はすべて架空。本番のスプシやLPとはつながっていません）

1. テスト用のスプシを開き、メニュー「拡張機能」→「Apps Script」
2. 最初からある `コード.gs` の中身を消して、`Ops.gs` の中身を貼る
3. 左の「ファイル」の「＋」→「スクリプト」で `OpsTestData` を作り、`OpsTestData.gs` の中身を貼る → 保存
4. スプシを開き直す → メニューに「TD台帳」が出る
5. 「テスト用のダミーを入れ直す」（初回は権限の確認が出るので許可）
6. 「列を整理する（最初に1回）」
7. 「一覧表を今すぐ作り直す」→ 出てきたリンクから「Class Structure（自動・テスト）」を開く
8. 必要に応じて「見張りメールを今すぐ送る」「今の一覧表を記録する（タブとPDF）」

求められる権限: スプシ（読み書き）、Drive（テスト用の Class Structure と記録のPDFを作る）、メール送信、外部へのアクセス（PDFの書き出し）、トリガー。

コードを新しくした時は、Apps Script の `Ops.gs`・`OpsTestData.gs` の中身を貼り替えて保存 →「テスト用のダミーを入れ直す」→「列を整理する（最初に1回）」→「一覧表を今すぐ作り直す」。

### 本番に入れる（テストで形が決まったあと）
1. `Ops.gs` の `BOARD_FILE_ID` に Class Structure のID（`1tK4hTrbKiqGTtL-2Efn6sqEOFxTpAKlB7cdhAOhqILU`）を入れる
2. 本番の Apps Script で「＋」→「スクリプト」→ `Ops` を作って貼る → 保存（`OpsTestData.gs` は入れない）
3. スプシを開き直し、「列を整理する（最初に1回）」（生徒シートの並べ替え・行の色、クラス一覧の「ターム・開始日」を「ターム」と「ターム開始日」に分ける）
4. クラス一覧の「ターム」（1〜6）と「ターム開始日」を埋める。今いる生徒の行に、クラス・開始日（海外は支払い済み〜も）を入れる（10/10より前の生徒はまだ行が無いので、入れ方は別に決める）
5. 「一覧表を今すぐ作り直す」
6. よければ「自動の更新を始める」（Ops のトリガーだけを作る。`processInbox` のトリガーには触らない）

`Ops.gs` を足すだけならウェブアプリの再デプロイは要りません（ウェブアプリはデプロイした版の `Code.gs` で動き、Ops はメニューとトリガーで動くため）。
列の並べ替えは `Code.gs` に影響しません（列名で読み書きしているため）。名前を変えるのは、GASが使っていない「提案クラス」→「クラス」と、クラス一覧の「ターム・開始日」→「ターム」「ターム開始日」です（`Code.gs` の readClasses_ はターム・開始日を読みますが、LPの `/api/slots` は使っていないので影響はありません）。
