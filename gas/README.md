# TDEN 生徒管理 GAS — 設置・更新手順

`Code.gs` はスプシ「TDEN 生徒管理」にバインドして使う Apps Script です。
このフォルダは `_redirects` でサイトから見えないようにしてあります。

- スプシ: https://docs.google.com/spreadsheets/d/14E9vIHQ46Uew7gFElSsimWIAUnnk8jhXcukGmOKO_eQ/edit
- 役割: LPの申込を受け付けて「生徒_JP／生徒_海外」に書き込む／「クラス一覧」の空き状況をLPに返す／activo と Airtable の通知メールを読み取って書き込む

## 初回の設置（Phase 1）

順番どおりに進めてください。

### 1. 旧GASの定期実行を止める
旧GAS（Japanese Applicants に転記しているプロジェクト）を開き、左の時計アイコン「トリガー」で `checkNewEmails` のトリガーを削除します。
止めないと、同じメールを新旧両方が取り込んで下書きも2通できます。

### 2. Airtable の通知メールに「国」の行を足す
Airtable → Automations →「Admin Notification - New Application」→ メール送信アクションの Message を開き、
1行目「TOMODACHI留学の新規お申込みがありました！」と空行のあと、「■ 名前:」の**上**に次の1行を足します。

```
■ 国: {Country}
```

（`{Country}` は「+」ボタンから Students の Country を選んで差し込む）。保存したら右上の **Update（変更を反映）** を押します。
新しいGASはこの行で「海外の申込」か「LPの予備経路（Japan）」かを振り分けます。

### 3. GASを貼り付ける
1. スプシ「TDEN 生徒管理」を開き、メニュー「拡張機能」→「Apps Script」
2. 最初からある `コード.gs` の中身をすべて消し、`Code.gs` の中身を貼り付けて保存（プロジェクト名は「TDEN 生徒管理」など）
3. 左の歯車「プロジェクトの設定」→ タイムゾーンを「(GMT+09:00) 日本標準時」に

### 4. 合言葉を作る
1. 上部の関数選択で `setApiKey` を選び「実行」
2. 初回は権限の確認が出るので許可（Gmail・スプシ・メール送信・外部からのアクセス）
3. 実行ログに出る `GAS_KEY = xxxxxxxx…` の xxxxxxxx… をコピー（後で Cloudflare に登録）

### 5. 定期実行を入れる
関数選択で `installTrigger` を選び「実行」。以後、5分おきに `processInbox` が動きます。

### 6. ウェブアプリとして公開する
1. 右上「デプロイ」→「新しいデプロイ」→ 歯車で種類「ウェブアプリ」
2. 説明: `v1`／次のユーザーとして実行: **自分**／アクセスできるユーザー: **全員**
3. 「デプロイ」→ 表示される「ウェブアプリのURL」（`https://script.google.com/macros/s/…/exec`）をコピー

「全員」にしても、合言葉（GAS_KEY）が無いリクエストはすべて拒否されます。

### 7. Cloudflare に登録する
Cloudflare → Workers & Pages → TDEN-LP のプロジェクト →「設定」→「変数とシークレット」→ 本番環境に追加:

| 名前 | 種類 | 値 |
|---|---|---|
| `GAS_URL` | テキスト | 6でコピーしたURL |
| `GAS_KEY` | シークレット | 4でコピーしたキー |

Airtable の `AIRTABLE_*` は予備経路で使うので**消さない**でください。

### 8. 動作確認（Claudeに依頼）
ここまで終わったら Claude に伝えてください。LP側をデプロイして、空き状況の表示とテスト申込を確認します。

## コードを更新したとき

Apps Script に新しい `Code.gs` を貼って保存 →「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→「デプロイ」。
こうするとURLは変わりません（「新しいデプロイ」を作るとURLが変わるので、Cloudflare の GAS_URL も直す必要が出ます）。

## 台帳の自動化（Ops.gs）— Phase 3

`Ops.gs` は、一覧表・月の記録・週1の見張りメール・列の整理・旧名簿からの取り込みを受け持ちます。
`Code.gs` と同じプロジェクトに、別のファイルとして置きます（関数・定数はすべて `ops`／`OPS` で始まるので、名前はぶつかりません）。
`OpsTestData.gs` はテスト用のスプシにだけ置くダミーデータ作りです。**本番には入れません。**

### 台帳のシート（生徒管理スプシ）

| シート | 中身 |
|---|---|
| 生徒_JP／生徒_海外 | 1人1行。ステータス・名前・電話（いつも見る所）。「受講中のクラス」は自動。提案中・空き待ちの時は「希望クラス」「希望開始日」。海外は「支払い済みの最終日」（期間で払うので支払待ちは使わない）。「WhatsApp」は定型文入りで開くボタン |
| 受講 | 1行＝1人×1クラス（生徒ID・クラス・席番号・開始日・最終日）。スタンダード2つ＋GAP なども書ける。席番号は空なら自動 |
| クラス一覧 | 1クラス1行。Class ID（曜日＋時刻＋講師コード）・状態（active／non-active）・種別（Standard／GAP）・講師・アシスタント・ターム |
| 講師 | 講師・アシスタントの名前・コード（JR・NM・MY など。アシスタントは無し）・カタカナ・役割・Zoom URL（講師だけ。クラス一覧の Zoom URL に自動で写す） |

non-active のクラスは、LPには今まで通り出します（クラス数を見せるため）。一覧表・名簿・取り込み・見張りメールのLP照合からは外します。

作るものは、見る人で3つに分かれます。

| ファイル | 見る人 | 中身 |
|---|---|---|
| 生徒管理（このスプシ） | あなただけ | 台帳＋「一覧表_今月／来月」（名前を押すと生徒の行が開く） |
| Class Structure（`BOARD_FILE_ID`） | スタッフ・講師（生徒には見せない）・英語 | 「26Oct (live)」「26Nov (live)」（5分おきに更新）と月の記録「26Oct」（月末に自動・あとから変わらない・PDFも）。リンク無し。講師の並びは `TEACHER_ORDER` |
| スタッフ用の名簿（`STAFF_FILE_ID`） | スタッフだけ | クラス別シート（席番号順・(admin)・Instructor／Assistant・1か月以内は緑・足りない情報は赤・Wix DB削除確認） |

### テスト用のスプシで試す
テスト用:「TDEN 生徒管理（テスト）」 https://docs.google.com/spreadsheets/d/1VRgvLnGfRyIBZPiP4qBAYJ2wIPGI72JmTbFy7rW9qxU/edit
（生徒はすべて架空。本番のスプシやLPとはつながっていません）

1. テスト用のスプシを開き、メニュー「拡張機能」→「Apps Script」
2. `コード.gs` に `Ops.gs` の中身、`OpsTestData.gs` に `OpsTestData.gs` の中身を貼って保存
3. スプシを開き直し、メニュー「TD台帳」を上から順に
   1. 「テスト用のダミーを入れ直す」
   2. 「列を整理する（最初に1回）」
   3. 「旧名簿から今の生徒を取り込む（最初に1回）」
   4. 「一覧表を今すぐ作り直す」→ 出てきた3つのリンクから開く

Googleアカウントに複数ログインしていると、確認の画面で止まることがあります（実行数に「一時停止」と出る）。シークレットウィンドウで、使うアカウントだけでログインして開いてください。

### 本番に入れる（テストで形が決まったあと）
事前にあなたがやること：旧名簿の古いクラスシートを直す（済）／本番のクラス一覧に、閉じたクラスは「non-active」と書く（済。列を整理するで「状態」列に移る）。

1. **先に Code.gs を新しくする**（クラス一覧の「Group ID」を「Class ID」に変えるので、LPの空き状況が読めるように）
   - 本番の Apps Script の `Code.gs` に新しい `Code.gs` を貼って保存 →「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」
2. `Ops.gs` の先頭に、3つのIDを入れる
   - `BOARD_FILE_ID`：Class Structure（`1tK4hTrbKiqGTtL-2Efn6sqEOFxTpAKlB7cdhAOhqILU`）
   - `STAFF_FILE_ID`：TD スタッフ用の名簿（`1OrnE2B-g5Fw_I0NNjkWQu7R87sGwMa33Hy32oHRXpAI`。スタッフだけに共有）
   - `OLD_FILE_ID`：旧名簿（`1AmV48Hi7OC-wZCY5_FpWjf1UEQt5mvEjDTyv6QqWNPk`。読むだけで書き換えない）
3. 本番の Apps Script で「＋」→「スクリプト」→ `Ops` を作って貼る → 保存（`OpsTestData.gs` は入れない）
4. スプシを開き直し、「列を整理する（最初に1回）」→ クラス一覧の「ターム」「ターム開始日」を埋め、講師シートのコード（JR・NM・MY）を確かめる
5. 「旧名簿から今の生徒を取り込む（最初に1回）」。最後に生徒を申込順に並べ直し、生徒IDも申込順に振り直す（10/10以降に付いたIDも変わる）
6. 「一覧表を今すぐ作り直す」。取り込んだ受講の開始日・最終日（海外は支払い済みの最終日）は、分かる所から入れる
7. よければ「自動の更新を始める」（Ops のトリガーだけを作る。`processInbox` のトリガーには触らない）

過去の生徒をあとから入れる時は、生徒IDを JX0001〜／GX0001〜 にする（今のIDは変えない。Code.gs の採番は「J＋数字」だけを数える）。
列の並べ替えは `Code.gs` に影響しません（列名で読み書きしているため）。名前を変えるのは、GASが使っていない「提案クラス」→「希望クラス」、「開始日」→「希望開始日」、クラス一覧の「Group ID」→「Class ID」（Code.gs は両方読む）と「ターム・開始日」→「ターム」「ターム開始日」です。
