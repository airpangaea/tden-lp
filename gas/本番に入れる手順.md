# 台帳（Ops.gs）を本番に入れる手順

所要時間：30分くらい。**シークレットウィンドウ**で、admin@airpangaea.com だけでログインして作業します（複数アカウントだと確認画面で止まるため）。

**Code.gs と Ops.gs の置き場所**：このプロジェクトの `gas` フォルダの中（`gas/Code.gs`、`gas/Ops.gs`）。ファイルを自分で開く必要はありません。Claude に「Code.gsをコピーして」「Ops.gsをコピーして」と言えば、クリップボードにコピーするので、Apps Script の画面で貼るだけです。

**3つのファイルのURL**（IDはこの中に入っています。Ops.gs にはIDだけを貼ります）
- Class Structure：https://docs.google.com/spreadsheets/d/1tK4hTrbKiqGTtL-2Efn6sqEOFxTpAKlB7cdhAOhqILU/edit
- スタッフ用の名簿：https://docs.google.com/spreadsheets/d/1OrnE2B-g5Fw_I0NNjkWQu7R87sGwMa33Hy32oHRXpAI/edit
- 旧名簿：https://docs.google.com/spreadsheets/d/1AmV48Hi7OC-wZCY5_FpWjf1UEQt5mvEjDTyv6QqWNPk/edit

---

## 0. 念のため控えを取る
本番スプシ「TDEN 生徒管理」→「ファイル」→「コピーを作成」。
（取り込みで生徒の並びとIDが変わるので、戻せるようにしておく）

## 1. Code.gs を新しくする（LPの空き状況のため・先にやる）
1. 本番スプシ →「拡張機能」→「Apps Script」
2. 「Claudeに『Code.gsをコピーして』と頼む」→ `Code.gs` の中身を全部消して貼る → 保存
3. 「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」
   - **「新しいデプロイ」は押さない**（URLが変わってLPが止まる）

## 2. Ops.gs を入れる
1. 同じ Apps Script で「＋」→「スクリプト」→ 名前を `Ops` にする
2. 「Claudeに『Ops.gsをコピーして』と頼む」→ 貼る
3. 先頭の3行に、IDを入れる（`''` の間に貼る）
   - `BOARD_FILE_ID: '1tK4hTrbKiqGTtL-2Efn6sqEOFxTpAKlB7cdhAOhqILU'`（Class Structure）
   - `STAFF_FILE_ID: '1OrnE2B-g5Fw_I0NNjkWQu7R87sGwMa33Hy32oHRXpAI'`（スタッフ用の名簿）
   - `OLD_FILE_ID: '1AmV48Hi7OC-wZCY5_FpWjf1UEQt5mvEjDTyv6QqWNPk'`（旧名簿）
4. 保存。**OpsTestData.gs は入れない**

## 3. メニューを順に押す
スプシを開き直すと、メニューに「TD台帳」が出ます。上から順に：

1. **列を整理する（最初に1回）**
   - そのあと、クラス一覧の「ターム」「ターム開始日」を埋める
   - 「講師」シートのコード（JR・NM・MY）とカタカナを確かめる
2. **旧名簿から今の生徒を取り込む（最初に1回）**
   - 終わると結果が出る。「足りない」「スキップ」があれば見ておく
3. **一覧表を今すぐ作り直す**
   - 出てきた3つのリンク（生徒管理の一覧表／Class Structure／スタッフ用の名簿）を開いて確かめる
   - 赤いマスは足りない情報。分かる所から埋める
4. よければ **自動の更新を始める**

## 4. 終わったら
- LPの空き状況が今まで通り出ているか、日本語LPと英語LPを開いて確かめる
- 「TD スタッフ用の名簿」をスタッフに共有する（編集できる人にする）
- Class Structure は生徒に共有しない

---

困ったら：エラーが出たら画面の文をそのまま Claude に送る。LPの空き状況が消えたら、1-3 の「新バージョン」でデプロイしたか確かめる。
